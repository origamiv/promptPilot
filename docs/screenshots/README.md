# Скриншоты веб-интерфейса

Скриншоты для README.md. Нужны следующие файлы:

| Файл | Что снять |
|------|-----------|
| `tasks.png` | Список задач — `/tasks` |
| `kanban.png` | Канбан-доска с карточками — `/kanban/<project>` |
| `workers.png` | Экран исполнителей — `/workers` |
| `priorities.png` | Справочник приоритетов с иконками — `/priorities` |
| `interactive.png` | Интерактивный терминал — `/interactive` |

Снимать на `http://localhost:8420/`.

Рекомендуемое разрешение: 1280×800, формат PNG.
