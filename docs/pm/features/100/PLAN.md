## Описание

Проверить, как работает фича скиллов в PromptPilot, и при необходимости дописать её.
Скилл — это `.md`-файл в `~/.claude/commands/`, который Claude Code запускает по команде `/skill-name`.
Нужно убедиться, что скилл добавлен в БД и на файловую систему, что UI показывает кнопку Skills при выборе агента claude, и что при реальном запуске задачи скилл выполняется.

## Текущее состояние (предварительный анализ)

### Уже готово ✅
- `hello-skill.md` существует в `/home/agent/.claude/commands/hello-skill.md`
- Скилл зарегистрирован в БД (`id=4`, `name="hello-skill"`, `agents=["claude"]`, `is_active=true`)
- API `/api/skills?provider=claude` возвращает скилл
- Frontend: кнопка Skills появляется при выборе провайдера `claude` вручную

### Найденный баг 🐛
- **Frontend bug в `selectWorker()`**: при выборе воркера с `agent_id` (например, PM-агент id=8, у которого `agent_id=1` = Claude), dropdown провайдера скрывается, но `updateSkillsToggle()` НЕ вызывается. Кнопка Skills не появляется, хотя должна.
- Нужно: при выборе воркера с `agent_id` — находить shortname агента, устанавливать `providerInput.value` и вызывать `updateSkillsToggle()`.
