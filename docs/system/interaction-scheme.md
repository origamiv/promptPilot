## Порядок запуска агентов

### Фаза 1 — Проектирование (параллельно)
- **Architect** — архитектура, API-контракт, ADR
- **UX Designer** — макеты экранов, экспорт PNG

### Фаза 2 — Реализация (после Фазы 1)
- **Database** — миграции по схеме от Architect
- **Backend** — Laravel API по контракту от Architect
- **Frontend** — Vue.js по макетам от UX + контракту от Architect
- **Mobile** — React Native по макетам от UX + контракту от Architect
- **Integrations** — воркеры по спецификации от Architect

### Фаза 3 — Контроль качества (после Фазы 2)
- **QA** — тесты на все реализованные компоненты
- **Reviewer** — ревью кода

### Фаза 4 — Деплой (после Фазы 3)
- **DevOps** — деплой на нужный стенд

## Правила параллельности

- Агенты внутри одной фазы могут запускаться параллельно
- PM создаёт все задачи фазы одновременно, затем ожидает их завершения
- Если задача агента переходит в `failed` — PM останавливает зависимые задачи и уведомляет человека
