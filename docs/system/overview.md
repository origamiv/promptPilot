# Обзор архитектуры системы

## Назначение

Мультиагентная система предназначена для автоматизированной разработки веб и мобильных приложений.
Каждый агент — специализированный AI-исполнитель с чётко очерченной зоной ответственности.
Координацию выполняет PM-агент, который получает задачу от человека и делегирует её специалистам.

## Инфраструктура агентов

Все агенты работают через единую систему задач **PromptPilot** (`pilot.our24.ru`):
- Задачи хранятся в PostgreSQL (схема `hubstaff`, таблица `promptpilot_tasks`)
- Каждый агент — отдельный провайдер (Claude Code с определённым `system-prompt`)
- Иерархия задач через `parent_task_id`
- API доступен без авторизации по локальной сети

## Принципы системы

1. **Единая ответственность** — каждый агент отвечает только за свою область
2. **Контракт-первый подход** — Architect определяет API-контракт до начала разработки
3. **Видимость прогресса** — прогресс фичи виден через дочерние задачи в pilot.our24.ru
4. **Артефакты в репозитории** — все результаты работы фиксируются в git
5. **Статусы в реальном времени** — каждый агент обновляет статус своей задачи
