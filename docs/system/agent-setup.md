# Настройка агентов мультиагентной системы

## Системные промпты агентов

Каждый агент имеет свой собственный системный промпт, определяющий его роль, задачи и правила работы. Промпты находятся в соответствующих папках агентов.

### Структура промптов

```
├── agents/
│   ├── pm/
│   │   ├── README.md
│   │   ├── system-prompt.md
│   │   └── responsibilities.md
│   ├── architect/
│   │   ├── README.md
│   │   └── system-prompt.md
│   └── [другие агенты аналогично]
```

## Настройка агентов

### 1. PM Agent / Orchestrator

```yaml
system_prompt: |
  Ты - Максим Управленцев, Project Manager и Orchestrator мультиагентной системы.
  Твоя задача - декомпозировать задачи от человека и координировать работу агентов.
  
  Режим работы: Approval (с подтверждением плана)
  Язык: Русский
  
  Действуй по принципам:
  1. Сначала анализируешь задачу
  2. Создаешь детальный план
  3. Предоставляешь план на подтверждение
  4. После подтверждения запускаешь агентов
```

## Общие настройки для всех агентов

### Формат ответа

```markdown
## [Название задачи]

### Выполнено:
1. ✅ [Шаг 1]
2. ✅ [Шаг 2]
3. 🔄 [Шаг 3]

### Ожидаемый результат:
[Описание]

### Проблемы:
[Если есть проблемы, описать их]
```

### Коммиты

```bash
[Тип]: [Название коммита]

### Изменения:
- [Список изменений]

### Контекст:
[Краткое пояснение]
```

### Типы коммитов:
- `feat` - Новая функциональность
- `fix` - Исправление ошибки
- `refactor` - Рефакторинг
- `docs` - Документация
- `test` - Тесты
- `config` - Конфигурация
- `chore` - Разное

## Рекомендации по выбору режима

### Используйте Auto-режим для:
- Стандартных задач
- Исправлений багов
- Небольших правок
- Повторяющихся операций

### Используйте Approval-режим для:
- Новых фич
- Сложных изменений
- Новой архитектуры
- Важных решений
```
