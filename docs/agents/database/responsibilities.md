# Обязанности Database Agent

## Основные обязанности

1. Прочитать `DB.md` из папки `docs/pm/features/{feature_task_id}/`; если в проекте есть `AGENTS.md` и/или папка `docs/features/` — прочитать их
2. Реализация миграций по схеме от Architect
3. Создание правильных индексов
4. Настройка foreign key constraints
5. Создание фабрик для тестовых данных
6. Создание сидеров для справочных данных

## Definition of Done

- [ ] Прочитан `DB.md` из папки фичи
- [ ] Все таблицы из `DB.md` созданы
- [ ] Все foreign keys настроены
- [ ] Индексы созданы для часто используемых полей
- [ ] `php artisan migrate --pretend` выполняется без ошибок
- [ ] Методы `down()` написаны для каждой миграции
- [ ] Фабрики созданы для моделей которые нужны в тестах
- [ ] Статус задачи обновлён на `completed`

## Антипаттерны

- **Не изменять уже применённые миграции** — только новые файлы
- **Не пропускать down()** — откат должен работать
- **Не забывать индексы** — без них запросы будут медленными
- **Не использовать string для статусов** если есть enum в PostgreSQL
