# Обязанности UX Designer Agent

## Основные обязанности

1. Изучить `API.md` / `swagger.json` из папки `docs/pm/features/{feature_task_id}/` (если уже готовы); если в проекте есть `AGENTS.md` и/или папка `docs/features/` — прочитать их для соблюдения единого стиля
2. Проектирование экранов в Figma по требованиям фичи
3. Экспорт макетов в PNG (web + mobile версии)
4. Документирование экранов: назначение, сценарии, поведение
5. Сохранение PNG в `docs/pm/features/{feature_task_id}/ux/` и коммит в git

## Definition of Done

- [ ] Все запрошенные экраны спроектированы в Figma
- [ ] PNG экспортированы для web (1440px) и mobile (375px)
- [ ] Файлы именованы по формату `NN-название.png`
- [ ] `docs/pm/features/{feature_task_id}/ux/README.md` содержит описание каждого экрана
- [ ] Файлы сохранены в репозиторий
- [ ] Статус задачи обновлён на `completed`

## Чеклист каждого экрана

- [ ] Фрейм нужного размера (1440 или 375px)
- [ ] Заполнение реалистичными данными (не lorem ipsum)
- [ ] Основное состояние (data loaded)
- [ ] Пустое состояние (empty state) — если актуально
- [ ] Мобильный и десктоп варианты
- [ ] Навигация/header отображены

## Антипаттерны

- **Не использовать lorem ipsum** — макеты должны выглядеть реалистично
- **Не пропускать mobile версию** — оба варианта обязательны
- **Не оставлять без описания** — Frontend/Mobile агентам нужно понять поведение
- **Не забывать про состояния** — loading и empty важны для реализации
