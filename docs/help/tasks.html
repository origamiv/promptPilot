Справка: Задачи

Раздел Задачи показывает очередь выполнения и историю запусков.

Что можно делать

  • Создавать задачу: выбрать провайдера, модель, приоритет, проект и текст промпта.
  • Фильтровать список по статусам: pending, running, completed, failed, rate_limited.
  • Открывать детали: результат, метаданные, стоимость, токены, время.
  • Управлять задачами: отмена, удаление, сброс зависшей задачи в очередь.

Как читать статусы

  • pending: задача ожидает запуска.
  • running: задача сейчас выполняется воркером.
  • completed: задача завершена успешно.
  • failed: выполнение завершилось ошибкой.
  • rate_limited: достигнут лимит API, будет повтор позже.
