Справка: Исполнители

Раздел Исполнители — справочник людей и агентов, которые выполняют задачи. Исполнитель может быть назначен на задачу и отображается на карточке задачи аватаркой.

Поля исполнителя

  • Имя — полное имя или название.
  • Short — краткий идентификатор (латиница).
  • Роль — должность или специализация (например, developer, tester).
  • Агент — связан ли исполнитель с агентом-аккаунтом системы.
  • Аватар — ссылка на изображение. Если не указана, генерируется автоматически через DiceBear по роли.
  • Статус — 0 = новый (требует верификации), 1 = активен, 2 = выключен, 3 = работает.

Аватары

  • Если поле «Аватар» заполнено — используется указанная ссылка на картинку.
  • Если у исполнителя установлен флаг «Агент» — генерируется аватар в стиле bottts (роботы).
  • Для обычных людей — стиль lorelei.

Назначение на задачу

  • При создании или редактировании задачи выберите исполнителя из выпадающего списка с аватарками.
  • Аватар выбранного исполнителя отображается на карточке задачи в разделе Задачи и на Канбан-доске.
