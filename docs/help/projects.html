Справка: Проекты

Раздел Проекты хранит список рабочих директорий, доступных для задач и интерактивной сессии.

Поля проекта

  • Name и Short: отображаемое имя и короткий идентификатор.
  • Folder: папка проекта (абсолютная или относительно корня проектов).
  • Color: цветовой маркер в интерфейсе.
  • Comment: заметка/контекст проекта.

Использование

Выбранный проект определяет рабочую директорию запуска CLI-команд.
