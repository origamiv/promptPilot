Справка: Промпты

Раздел Промпты хранит шаблоны, которые можно переиспользовать при создании задач.

Для чего нужен

  • Единый каталог системных и рабочих шаблонов.
  • Быстрая сборка финального запроса из нескольких коротких промптов.
  • Унификация стиля постановки задач для команды.

Совет

Разделяйте промпты на роли: базовые, проектные, проверочные, финализирующие.
