Справка: MCP серверы

Раздел MCP серверы — справочник расширений для Claude. MCP (Model Context Protocol) серверы добавляют новые инструменты и возможности: интеграции с мессенджерами, таск-трекерами, документацией и другими сервисами.

Поля MCP сервера

  • Имя — полное название MCP сервера (например, YouGile, Telegram).
  • Shortname — краткий уникальный идентификатор латиницей (например, yougile, telegram). Используется для ссылок и конфигурации.
  • Описание — краткое описание назначения сервера.
  • Команда — исполняемый файл для запуска сервера (например, npx, bun).
  • Args — JSON массив аргументов командной строки. Пример: ["-y", "@yougile/mcp"]
  • Env — JSON объект переменных окружения, передаваемых серверу. Пример: {"TOKEN": "abc123"}
  • Options — JSON объект дополнительных настроек MCP сервера.
  • Статус — 0 = выключен, 1 = активен.

Формат команды запуска

  • Поле Команда содержит только имя исполняемого файла: npx, bun, node и т.д.
  • Аргументы передаются отдельно в поле Args в виде JSON массива строк.
  • Пример для Context7: команда npx, args ["-y", "@upstash/context7-mcp"]
  • Пример для Bun-плагина: команда bun, args ["run", "--cwd", "/path/to/plugin", "--shell=bun", "--silent", "start"]

Как добавить новый MCP сервер

  • Нажмите кнопку Добавить MCP в верхней части раздела.
  • Заполните обязательные поля: Имя и Shortname.
  • Укажите команду запуска и аргументы в формате JSON массива.
  • При необходимости добавьте переменные окружения в поле Env.
  • Сохраните запись — сервер появится в списке доступных MCP.

Предустановленные MCP серверы

  • Context7 — документация библиотек через Context7 (npx -y @upstash/context7-mcp).
  • iMessage — интеграция с iMessage для отправки и получения сообщений.
  • Discord — интеграция с Discord.
  • Telegram — интеграция с Telegram.
  • Fake Chat — фейковые чаты для тестирования без реальных мессенджеров.
  • Linear — интеграция с Linear (таск-трекер).
  • YouGile — интеграция с YouGile (таск-трекер).
