Справка: Агенты

Раздел Агенты хранит логические сущности исполнителей (профили агентов).

Назначение

  • Создание и редактирование списка агентов для маршрутизации задач.
  • Задание приоритета и статуса агента.
  • Связь с аккаунтами агентов в разделе «Аккаунты агентов».

Рекомендация

Если у вас несколько API-аккаунтов, создайте отдельные аккаунты и привяжите их к нужному агенту.
