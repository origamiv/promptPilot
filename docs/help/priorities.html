Справка: Приоритеты

Раздел Приоритеты — это справочник приоритетов задач с именем, коротким кодом и иконкой.

Поля

  • ID — идентификатор записи.
  • Название — отображаемое имя приоритета.
  • Short — короткий код (уникальный).
  • Иконка — URL изображения (обычно SVG).
  • Статус записи — 1 = включён, 0/2 = выключен.

Предзагруженные приоритеты

По умолчанию загружаются приоритеты Jira из строки NEW: blocker, critical, major, highest, high, medium, low, lowest, minor, trivial.

Как использовать

  • Откройте меню Справочники → Приоритеты.
  • Создайте новую запись кнопкой + или отредактируйте существующую.
  • Для удаления используйте кнопку Delete.
  • Поиск работает по полям name и shortname.
